  - _Contributions:_ The paper proves that the cross-attention mechanism is rotation-invariant when its query is held fixed and its source (key/value) tokens are rotated, and uses this to derive design principles for a Rotation-Invariant Text Decoder (RITD). It also proposes RELG, a rotation-equivariant local-global backbone combining deep equivariant convolutions with self-attention to preserve fine-grained detail and model inter-character dependencies. Combining RELG and RITD yields RISTER, an end-to-end rotation-invariant scene text recognizer that needs no orientation-estimation module or rotation-based data augmentation.
  - _Applicable to our work:_ Our own 'make the encoder natively rotation-invariant' line is closed, but this paper's most transferable idea is decoder-side and architecture-agnostic: constructing the decoder's query purely from already-emitted output tokens (not from the raw, possibly-rotated input features) makes any subsequent cross-/pointer-attention over the input features provably invariant to whatever transformation was applied to those features. Applied to our pointer/copy decoder over B-rep faces, this suggests forming the pointer query solely from the previously-emitted program tokens (never mixing in raw per-face coordinate features into the query itself) so that the face-addressing/copy attention becomes provably rotation-invariant regardless of how the B-rep's face features are rotated — a decoder-only change that doesn't require revisiting the (closed) equivariant-encoder question. The underlying proof technique (cross-attention over an unordered token set is invariant to any joint transform of keys/values given an invariant query) generalizes beyond 2D images to graphs/sets in general.
  - _Additional context:_ Because our 'encoder rotation-invariance' line is explicitly closed per the problem statement, most of this paper's direct architectural contribution (the RELG equivariant-convolution backbone, tied to a discrete C4 group over 2D pixel grids) has limited transfer value and does not obviously port to 3D SE(3) B-rep face graphs, which are non-grid and variable-cardinality. The decoder-side invariant-query trick is the one genuinely new, cheaply-testable mechanism, and it is worth flagging that RISTER's guarantee is exact only at 4 canonical angles and approximate elsewhere — our own rotation robustness needs are likely continuous (arbitrary part orientation), so the guarantee would only partially transfer.
